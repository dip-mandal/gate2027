# GATE/27 Prep Lab

Responsive, static GATE 2027 Computer Science & Information Technology study workspace built with HTML, CSS and vanilla JavaScript.

## Learning features
- **Study Library:** original topic lessons organised by subject and chapter, with searchable navigation
- Core theory, high-yield points, examples, formulas, common traps and time-saving methods
- Interactive step-by-step walkthroughs for selected numerical topics
- Animated concept flow, text diagrams and KaTeX math rendering
- Topic completion tracking in browser local storage
- Persistent light/dark theme
- Subject checklist, MCQ/MSQ/NAT sample practice, formula cards and local performance analytics
- Exam-day time management playbook

The study library currently contains 58 lesson entries across the 11 principal CS/IT and General Aptitude subject areas. These are learning modules, not a claim that every line-item in the official syllabus has already been taught in textbook depth. Continue expanding and validating coverage topic-by-topic against the revised 2027 syllabus.

## Run locally
Open `index.html` directly or serve the repository with a static web server. Progress and theme preferences are saved locally in the browser.

## Custom domain / deployment note
The repository's current `CNAME` file is set to `gate.meixup.in`. The requested domain `gate.meixup.com` is different. Do not switch the repository's custom domain until the intended hostname and its DNS records are confirmed. Public web checks from this environment could not load either custom domain reliably, so deployment is **not confirmed** here.

## Publish using GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/(root)`, then save. If using a custom domain, configure the same exact hostname in GitHub Pages and set its DNS records according to GitHub's current documentation.
