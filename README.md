# GATE/27 Prep Lab

A responsive, static study workspace for GATE 2027 Computer Science and Information Technology. Built with HTML, CSS and vanilla JavaScript.

## Current features
- Dashboard and subject checklist with browser-local progress
- **Study Library:** 11 subject areas and 46 topic lessons, organized by subject and chapter
- Each lesson includes explanatory theory, high-yield points, a worked example, a visual/ASCII diagram, common traps and a time-saving tip
- Search and subject/chapter filters, previous/next lesson navigation
- KaTeX support for displaying mathematical notation
- Persistent light/dark mode switch
- MCQ/MSQ/NAT sample practice with explanations
- Searchable formula cards and browser-local progress analytics
- Exam-day time-saving playbook

## Run locally
Open `index.html` directly, or serve the repository with any static web server. Study lessons and progress are client-side; progress is stored in your browser's local storage.

## Official syllabus
Always cross-check coverage against the official GATE 2027 CS syllabus:
https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf

## Publish with GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Once the deployment completes, the expected URL is:
https://dip-mandal.github.io/gate2027/
