# GATE/27 Prep Lab

A personal GATE 2027 Computer Science preparation platform built with HTML, CSS and vanilla JavaScript.

## Status
Starter scaffold: dashboard, syllabus checklist, practice engine, formula deck, diagnostic page and analytics. Content is being expanded and audited against the official syllabus.

## Official syllabus
https://gate2027.iitm.ac.in/static/doc/GATE2027_Syllabus/CS_GATE2027_Syllabus.pdf

## Run
Open `index.html` or serve this directory with a static server. Progress is stored locally in the browser.

## Disclaimer
Independent study project; not affiliated with IIT Madras or GATE. Starter questions are illustrative, not official PYQs or guaranteed predictions.
